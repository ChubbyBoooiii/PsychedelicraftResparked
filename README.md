# Psychedelicraft Resparked
A Forge 1.12.2 port/rewrite of [Ivorforce's Psychedelicraft](https://github.com/Ivorforce/Psychedelicraft) (originally built for 1.7.10).

## Requirements
- Minecraft 1.12.2
- Forge 14.23.5.2847 (or compatible)
- [MixinBooter](https://www.curseforge.com/minecraft/mc-mods/mixin-booter) 10.2+ (required)
- [JEI](https://www.curseforge.com/minecraft/mc-mods/jei) (optional, but recommended as it adds recipe lookups for the drying table and fluid crafting process)

## What's in it
- A recreation of the original Psychedelicraft, with some inspiration taken from the Fabric continuation. Started as a port, but I was rewriting a good bit anyways so thought I should just try my best to make it faithful while adding/removing some stuff.
- Mod integrations: JEI support, IE garden cloche compat, AgriCraft crop support.

## Installation
1. Install Forge 14.23.5.2847 (or compatible) for Minecraft 1.12.2.
2. Install [MixinBooter](https://www.curseforge.com/minecraft/mc-mods/mixin-booter).
3. Drop the mod jar into your mods folder.
